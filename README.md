# qa-ecommerce-portofolio

![CI](https://github.com/Eugen076/qa-ecommerce-portofolio/actions/workflows/ci.yml/badge.svg?branch=main)

QA Portofolio Project - Manual Testing, Selenium Automation, API Testing and SQL

## Continuous Integration

GitHub Actions runs the Selenium/TestNG tests on pushes and pull requests targeting `main`, and can also be started manually from the Actions tab. Test reports and failure screenshots are available in the workflow run's **Artifacts**.
