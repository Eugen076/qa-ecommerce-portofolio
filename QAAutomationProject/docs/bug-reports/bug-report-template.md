# Bug Report Template

| Field | Details |
|---|---|
| ID | Unique identifier, for example `BUG-004` |
| Title | Short, specific description of the behavior |
| Severity | Critical, High, Medium, or Low; describe impact |
| Priority | P1 (urgent), P2 (normal), or P3 (low) |
| Environment | Browser/version, operating system, and SauceDemo username used |
| Preconditions | Required account state, page, cart contents, or other setup |
| Steps to reproduce | Numbered, repeatable actions |
| Expected result | Behavior expected from the user or product perspective |
| Actual result | Observed behavior, including visible messages or state |
| Attachments | Screenshot, log, or evidence location; write `None` if not captured |
| Status | New, Open, In Progress, Resolved, or Closed |
| Reporter | Name or project/team role |
| Date | Date the behavior was reproduced (`YYYY-MM-DD`) |
